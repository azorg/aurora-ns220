# 0001. Аудит нового устройства: чек-лист «сможем ли мы здесь разрабатывать»

Статус: применим (проверен на NS220/MVK-2020, Aurora 4.0.2.340).
Источник: перенесён из `~/work/clear-ssh/cterm/aurora/doc/ai/audit/audit-checklist.md`,
2026.11.21 — это базовый чек-лист для расширения проекта на другие устройства
(см. TODO «Универсальный стенд»).

Порядок проверок, который позволяет за ~30–60 минут понять, годится ли планшет/устройство
на Aurora (или аналогичной ОС) как стенд разработки. Все команды — с устройства (root).

## A1. Идентификация

```bash
uname -a; cat /etc/os-release; ssu re 2>/dev/null; ssu status 2>/dev/null
getprop ro.product.device 2>/dev/null; cat /proc/cpuinfo | grep -m1 -E "model name|Processor"
cat /proc/meminfo | head -1
lsblk; cat /proc/partitions | head -30
cat /proc/cmdline
```

Фиксируем: SoC, версию ОС, ядро, размеры разделов, cmdline (там же параметры IMA/secure boot).

## A2. Доступ (root/SSH)

```bash
ls -l /usr/bin/devel-su /bin/su
echo 1234 | devel-su id            # работает ли devel-su
systemctl status sshd | head -5
grep -E '^PermitRootLogin' /etc/ssh/sshd_config
ip -br addr                         # есть ли RNDIS/адрес для ssh
```

Если `sshd` есть — включить root-логин и работать по SSH (удобнее, чем через экран).

## A3. Защита исполнения (главное!)

```bash
cat /proc/cmdline | tr ' ' '\n' | grep -E 'ima_|sig_enforce|selinux|security='
cat /sys/kernel/security/ima/violations 2>/dev/null
getfattr -m- -d /usr/bin/git | head -3     # есть ли security.ima у системных бинарников

# тест «можно ли запускать своё»
printf '#!/bin/sh\necho OK\n' > /tmp/t.sh; chmod 755 /tmp/t.sh; /tmp/t.sh
printf 'int main(){return 0;}' > /tmp/t.c; gcc -o /tmp/t /tmp/t.c 2>/dev/null && /tmp/t && echo BIN_OK
```

Выводы:
* `ima_appraise=enforce` + отказ в запуске → нужен §10 (правка cmdline boot-образа).
* Если запускается — прекрасно, IMA выключен/не настроен.

## A4. Композитор (графика)

```bash
ls -l /run/display/wayland-* /run/user/*/wayland-* 2>/dev/null
tr '\0' '\n' < /proc/$(pgrep -f lipstick | head -1)/environ | grep -E 'WAYLAND|XDG'
# глобалы (см. patches/wlinfo.c)
gcc -o wlinfo patches/wlinfo.c -lwayland-client
XDG_RUNTIME_DIR=/run/user/$(id -u) WAYLAND_DISPLAY=<путь> ./wlinfo
```

Ключевое: есть ли `xdg_wm_base` (тогда GLFW/Fyne работают без патча) или только `wl_shell`
(нужен наш патч). Есть ли `zwp_text_input_manager` (системная клавиатура для Fyne).
Есть ли `wl_touch` в `wl_seat.capabilities`.

## A5. GL/EGL

```bash
ls /usr/lib/libEGL* /usr/lib/libGLESv2* 2>/dev/null
ldd /usr/lib/libEGL.so.1 | head -5          # hybris?
ls /usr/lib/dri 2>/dev/null | head           # есть ли Mesa swrast
# есть ли в репозитории Mesa-llvmpipe
zypper se -s mesa-llvmpipe | head
```

Если EGL — libhybris (android), для GLFW/Fyne потребуется Mesa llvmpipe (см. `03-TOOLCHAIN.md`)
либо путь через `android_wlegl`.

## A6. Инструменты и пакеты

```bash
for c in gcc g++ make git python3 cmake rpm rpmbuild zypper; do printf "%s: " $c; command -v $c || echo -; done
zypper se -s wayland-devel libxkbcommon-devel gcc-c++ cmake | head
ssu lr          # какие репозитории доступны (публичные/закрытые)
```

## A7. Сборка теста (минимальный smoke-тест Go+Fyne)

```bash
mkdir -p /tmp/t && cd /tmp/t
cat > go.mod <<'EOS'
module t
go 1.21
require fyne.io/fyne/v2 v2.4.4
EOS
# main.go — окно с меткой (см. doc/04-BUILD-RUN.md)
go mod edit -replace github.com/go-gl/glfw/v3.3/glfw=<путь к патченному модулю>
go mod tidy && go build -tags "wayland gles egl" -o t .
XDG_RUNTIME_DIR=... WAYLAND_DISPLAY=... ./t
```

Проверить: окно видно, текст читаем (`FYNE_SCALE`), тап/свайп доходят (после патча `wl_touch`).

## A8. Прочее (важно для стенда)

```bash
df -h / /home              # место (Fyne-бинарник ~24 МБ, Go ~400 МБ)
mount | grep ' /home '     # noexec?
ls -l /dev/fb0             # можно ли делать скриншоты
cat /proc/swaps            # swap (для сборки пригодится)
systemctl list-units --failed
```

## A9. Итоговая таблица решения

| Проверка | Если «нет» |
|---|---|
| root (devel-su) | без root дальше почти ничего нельзя |
| запуск своих бинарников (IMA off) | править boot cmdline / подпись |
| Wayland-сокет доступен | GUI невозможен без своего композитора |
| xdg-shell | нужен патч GLFW (`wl_shell`) |
| EGL пригоден для wl_egl_window | Mesa llvmpipe или android_wlegl |
| touch в seat | нужен патч GLFW `wl_touch` |
| text-input manager | нужна своя экранная клавиатура |
| Go/toolchain ставится | иначе кросс-сборка с хоста (но бинарник должен запускаться) |
