# doc/ai — текстовые документы (стиль RFC)

Длинные документы проекта пишутся здесь. Короткие заметки — в существующие
документы (REPORT, doc/00-INDEX.md), новые файлы — не плодить.
Язык — русский. Дата и цель — в заголовке. «Проверено» держать отдельно от
«гипотезы».

## Структура

| Каталог | Назначение | Формат |
|---|---|---|
| `plans/` | Планы работ, по одному файлу на задачу | `NNNN.plan-<имя>.md`, номер нумеруется по порядку и совпадает со ссылкой в TODO.txt |
| `bugs/` | Известные проблемы | `README.md` — реестр `B0NN: симптом → причина → решение` (проверено, реально встречалось); крупные кластеры — отдельные файлы (`osk-host-bugs.md`) |
| `audit/` | Аудиты, чек-листы, gap-анализы | `NNNN.<имя>.md` |
| `notes/` | Журналы экспериментов | `experiment-log.md` — записи «дата, гипотеза, команды, результат» (новые сверху) |
| `inquiries/` | Запросы вендорам | `NNNN.<имя>.txt` |

## Формат плана (`plans/NNNN.plan-<имя>.md`)

```
# NNNN. <Название> (статус: активен/в работе/закрыт, ГГГГ.ММ.ДД)

Цель: <одним-двумя абзацами>
Контекст: <почему, что уже есть, ссылки на REPORT/doc>
Этапы:
  P0. <...>  [x]
  P1. <...>  [ ]
Приёмка: <измеримый критерий «готово»>
```

## Формат бага (`bugs/`)

```
## B0NN. <Кратко>
**Симптом:** ...
**Причина:** ...
**Решение:** ... (команды/патчи; ссылок на файлы репо)
```

Новый баг = следующая номера в `bugs/README.md`; баг, у которого нет
решения, помечается `(в поиске)`.

## Формат записи журнала экспериментов (`notes/experiment-log.md`)

```
### ГГГГ.ММ.ДД — <гипотеза/опыт>
Команды: ...
Результат: ...
Вывод: ... (проверено/опровергнуто)
```
