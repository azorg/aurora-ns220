# 0016. Периферия в тестовом приложении: звук, микрофон, вибро, GPS, G-сенсор (статус: в работе, 2026.11.21)

Цель: одно окно `apps/hello-ns220`, в котором видно и слышно всё, что даёт железо:
подача звука, уровень микрофона в дБ, виброклик на тап, GPS, G-сенсор. Это
«супер-тест» стенда и одновременно заготовка библиотеки доступа к периферии
(позже — общий RPM `aurora-fyne-runtime`/`pkg/aurora/*`).

Документация API и замеры — `doc/15-PERIPHERALS.md`; проблемы — bugs B031–B034.

## Приёмка

На устройстве: тон слышен, вибро ощущается, бар микрофона реагирует на голос,
GPS показывает статус (и координаты на улице), G-сенсор либо показывает значения,
либо явно сообщает об ограничении; всё это — из одного окна, установленного RPM.

## Известные ограничения

* G-сенсор: MTK HAL отвергает `setDelay` → sensorfw не получает данные (B031);
  прямые пути (ioctl `/dev/gsensor`, HAL через libhybris, i2c-dev, QtSensors) не
  дали данных — нужен отдельный адаптер/обход.
* GPS: без фикса в помещении статус 1; координаты NaN (B032 — как читать).
* Звук/микрофон требуют, чтобы сессия пользователя была активна
  (`XDG_RUNTIME_DIR=/run/user/100000`, PulseAudio в сессии).
