# 0015. Тестовое приложение «Hello NS220» (Go + Fyne + OpenGL) (статус: работает, 2026.11.21)

Цель: практическое доказательство, что на планшете возможна разработка GUI на
Go/Fyne, полный цикл «исходник → сборка на устройстве → запуск → снимок →
RPM-пакет → подпись». Приложение — база для дальнейших экспериментов с
периферией (туда же будут добавляться пробы звука, сенсоров, кнопок и т.д.).

Код: `apps/hello-ns220/` (main.go, board.go, input.go, selftest.go, devinfo.go,
screen.go, shot.go, packaging/). Подробности — `apps/hello-ns220/README.md`.

## Что делает

* выводит приветствие и сведения об окружении (ОС, ядро, CPU, GPU, режим IMA,
  версии Fyne/GLFW);
* рисует анимацию (лучи + летающие круги) через OpenGL/Fyne и показывает два FPS:
  тики анимации и фактические перерисовки;
* показывает точку касания (перекрестие, кольцо, затухающий след, «волны»);
* распознаёт тап, двойной тап, долгое нажатие, свайпы в 4 стороны,
  перетаскивание, прокрутку — со счётчиками и последним жестом в HUD;
* имеет `-selftest` (прогон жестов без тачскрина) и `-shot` (снимок окна в PNG)
  для удалённой проверки.

## Приёмка

`rpm -q aurora-hello-ns220` → установлен; запуск из меню открывает окно; на
экране FPS, точка касания и счётчики жестов; при жестах счётчики растут;
`rpm -Kv` подтверждает нашу подпись.

## Найденные проблемы (внесены в реестр)

B023 (`fyne.Do` из анимации), B024 (`SetFullScreen` на wl_shell),
B025 (XKB compose/локаль), B026 (`rpm-sign`/rpmsign), B027
(`brp-strip-static-archive`), B028 (определение GPU до старта GL).
