# 0008. Сборка RPM для NS220 и go+fyne-runtime (статус: в работе, 2026.11.21)

Цель: научиться собирать корректные RPM для этого планшета (`noarch` и `armv7hl`,
arch = `armv7hl`? проверить `rpm --eval '%_arch'`), уметь их ставить/удалять,
и выпустить пакет с общими библиотеками для наших Go+Fyne-приложений.

Контекст (REPORT §6, §7): на устройстве есть `rpm-build`; валидация пакетов —
`/usr/lib/rpm-plugins/validation.so` + `/usr/share/rpm-validator/configuration.json`
(хуки tsm_pre/tsm_post) требует CMS-подпись «developer», цепочку к
`/etc/keys/packages/ca.pem` и keyid == `/etc/keys/packages/system-developer-keyid`.
Пока IMA выключен, требование подписи можно обходить; но для «правильного»
пакета нужен план 0009.

Драфт spec’а: `pkg/aurora-fyne-runtime.spec` (создать; см. план 0008 P3).

## Приёмка

`rpm -qa | grep aurora-fyne` → пакет стоит; приложение из него запускается из
меню; `rpm -e` чисто удаляет; spec и инструкция сборки — в репо; повторная
сборка с нуля на чистом хосте воспроизводит те же пакеты.

## Заметки

* Малый смысл собирать на самом планшете (медленно): кросс-сборка Go — легко
  (`GOARCH=arm GOARM=7`), C-часть (GLFW) — только нативно/через chroot (plan 0004).
* Mesa-llvmpipe RPM из Aurora (`mesa-llvmpipe-*-devel`) ставиться не должен —
  конфликт с adaptation; заголовки распаковывать без установки.
