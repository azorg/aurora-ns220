# 0007. Запуск Go/Fyne-приложений «как Aurora» (меню, booster, tray) (статус: запланирован, 2026.11.21)

Цель: наши Go/Fyne-приложения запускаются из меню приложений Aurora, ведут себя
как штатные (иконка, имя, единственный экземпляр, trayIcon), ставятся RPM.

Контекст: сейчас Fyne-приложение запускается вручную из shell с переменными
окружения (EGL_PLATFORM, DBUS_SESSION_BUS_ADDRESS, XDG_RUNTIME_DIR). Штатный
путь Aurora: `.desktop` → `invoker`/`booster` → sandbox (firejail-подобные
профили Sailfish). Нужно понять, что именно требует lipstick.

## Приёмка

Иконка в меню Aurora; тап запускает приложение; второй тап — активирует
существующее окно; приложение закрывается штатно; пакет ставится/удаляется
RPM без ручных шагов.

## Риски

* booster/sandbox может запрещать доступ к `/dev/mali0` или Wayland-сокету —
  тогда «легальный» обход: свой `.desktop` с прямым Exec + окружение.
* lipstick может требовать подписи/определённого типа приложения — проверить
  на тестовом `.desktop` до упаковки.
