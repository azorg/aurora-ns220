# 0004. Debian chroot на планшете (статус: РАЗВЁРНУТ, 2026.11.21)

Цель: получить на планшете полноценный пользовательский Linux (apt, nmap, mc,
tmux, vim, свежие gcc/go/rust), не мешая Aurora.

Контекст: рецепт сборки/разворачивания описан в `doc/11-DEBIAN-CHROOT.md`
(debootstrap --foreign --arch=armhf bookworm, ~84 МБ, второй этап — на планшете,
он armv7). GUI внутри chroot не выйдет (нет доступа к lipstick) — только CLI;
для GUI-приложений — Fyne/RPM вне chroot.

## Приёмка

`deb` открывает shell в bookworm; apt работает; набор утилит установлен;
chroot не ломает Aurora (после выхода — `systemctl --failed` пусто);
всё зафиксировано в ChangeLog.ai.

## Риски

* `/home` — noexec: бинарники chroot должны лежать на разделе с exec.
* Дублирование библиотек: не монтировать `/usr` Aurora внутрь chroot.
* Проброс `/run/user/100000` (pulse) и `/dev/mali0` — для GUI/аудио вне chroot.


## Результат развёртывания (2026-11-21)

* rootfs: `debian-armhf-rootfs.tgz` (debootstrap --foreign bookworm armhf), второй этап
  выполнен на устройстве: `chroot … /debootstrap/debootstrap --second-stage` → OK.
* apt: `apt-get update` и установка пакетов работают (публичный DNS внутри chroot,
  `Acquire::ForceIPv4`, `APT::Sandbox::User root`).
* вход: `/usr/local/bin/debian-chroot` (он же `deb`), из меню — «Debian (chroot)»
  (`fingerterm -e /usr/local/bin/debian-chroot`).
* ограничение: GUI внутри chroot нет (нет доступа к сессии lipstick/Wayland);
  только CLI, для GUI — Fyne/Qt вне chroot.
* ⚠️ `/home` в Aurora монтируется `noexec` — вход и сборка требуют
  `mount -o remount,exec /home` (обёртка делает это сама, нужен root).
