# Экранные клавиатуры для программирования: обзор и выводы для cterm/Aurora

Дата: 2026.11.21. Задача: собрать лучшие практики экранных клавиатур (OSK) для
планшетов и смартфонов, пригодных для работы в терминале и редакторе, и
сформулировать требования к собственной клавиатуре cterm на Aurora OS
(планшет NS220/MVK-2020, 1216×1920, ~264 dpi, ARMv7).

Скриншоты сохранены ВНЕ репозитория — `~/aurora-ns220/osk-screens/screens/`
(и `.../screens-host/`, манифест с sha256 — `screens/MANIFEST.md`, см. `AGENTS.md`),
источники — официальные страницы
проектов и магазины приложений.

## 1. Ограничения нашей платформы (Aurora, планшет)

| Факт | Следствие для OSK |
|---|---|
| Системная клавиатура недоступна сторонним клиентам Wayland (нет `zwp_text_input_manager_v3`/`zwp_input_method`, `cterm/aurora/doc/09-TOUCH-AND-KEYBOARD.md` §9.4) | Своя OSK внутри cterm — **единственный** путь |
| Тач приходит как `wl_touch`; GLFW патчится до мыши (`patches/glfw-aurora.patch`) | Тап/двойной тап/drag работают; **двухпальцевый скролл пока не эмулируется** |
| Экран 1216×1920 (портрет), 264 dpi | Клавиши ≥ 48 px по короткой стороне; OSK не должна закрывать строку ввода |
| Планшет (NS220), а не телефон | Кнопки громкости как Ctrl/Alt — **неудобно** (см. §4.3), только опция |
| 4 ядра ARMv7, программный OpenGL (llvmpipe) | OSK без анимаций/блюра; перерисовка только по событию |

## 2. Методика

- Поиск: «programming keyboard android», «extra keys row terminal android»,
  «terminal keyboard Esc Ctrl Tab iOS», «code keyboard iOS».
- Отбор: только проекты, где **есть реальные модификаторы** (Ctrl/Alt/Esc) и

## 3. Лучшие OSK для Android

### 3.1 Unexpected Keyboard (Julow) — эталон «программистской» OSK
Источник: <https://github.com/Julow/Unexpected-Keyboard>, F-Droid/Play.

- Полноценный QWERTY-ряд + цифровой ряд; **дополнительные символы по свайпу в
  углы клавиши** (не нужно переключать раскладку ради `~ | \ { } [ ] $`).
- Изначально спроектирована для Termux: есть **Esc, Tab, стрелки, Ctrl/Alt/Meta**,
  `F1..F12`, Home/End/PageUp/PageDown/Delete/Insert.
- Модификаторы «липкие» (нажал — действует на следующую клавишу), есть блокировка
  (double-tap).
- Настраиваемые раскладки (JSON) и несколько языков, в т.ч. русская.
- Скриншоты: `screens/unexpected-1..6.png`.

**Что забрать:** свайпы по клавишам для символов; липкие модификаторы; отдельный
цифровой ряд опцией; «программистская» раскладка как отдельный профиль.

### 3.2 Hacker's Keyboard — эталон «полного PC-ряда»
Источник: <https://github.com/klausw/hackerskeyboard>.

- Пять рядов как на ноутбуке: отдельный цифровой ряд, знаки препинания на своих
  местах, **стрелки, Tab/Ctrl/Esc работают** (проект делался для ConnectBot/SSH).
- Мультитач-модификаторы (можно держать Ctrl и нажимать клавишу).
- Раскладки десятков языков, включая русскую и фонетическую.
- Ограничение: проект 2011 года (AOSP Gingerbread), на новых Android часть
  функций (переключение языка, popup-клавиши) деградировала.

**Что забрать:** привычное расположение (Backspace в верхнем ряду, Enter справа),
отдельный ряд цифр, «полный» режим для планшета.

### 3.3 FlorisBoard и HeliBoard (OpenBoard) — эталон кастомизации
Источники: <https://github.com/florisboard/florisboard>,
<https://github.com/HeliBorg/HeliBoard>.

- Современные open-source клавиатуры: темы, раскладки, **встроенный менеджер
  буфера обмена**, жесты, предиктивный ввод.
- Программистских модификаторов «из коробки» нет (Ctrl/Esc решаются жестами или
  внешним рядом), но архитектура расширений и тем — хороший ориентир.

**Что забрать:** тема OSK из палитры терминала (как остальной UI cterm), история
буфера обмена — отдельной панелью, а не «магическим» жестом.

### 3.4 Системные клавиатуры + кнопки громкости (как в Termux)
Источник: <https://wiki.termux.com/wiki/Touch_Keyboard>.

Termux не рисует свою OSK, а использует системную и **кнопки громкости**:

| Комбинация | Действие |
|---|---|
| Volume Down + клавиша | Ctrl + клавиша |
| Volume Up + E | Escape |
| Volume Up + T | Tab |
| Volume Up + 1..0 | F1..F10 |
| Volume Up + B / F | Alt+B / Alt+F (по слову в readline) |

**Вывод:** это компромисс для телефонов в одну руку. На планшете NS220 кнопки
громкости на торце — тянуться к ним двумя руками неудобно, к тому же они
перехватываются системой. Поэтому в cterm для Aurora это **опция (по умолчанию
выключена)**, а не основной способ ввода. В отчёте фиксируем как «fallback для
телефонов».

## 4. Лучшие OSK для iOS

### 4.1 Blink Shell — «Smart Keys»
Источник: <https://docs.blink.sh/> (раздел Quick Start → Smart Keys).

- Над системной клавиатурой — **ряд Smart Keys**: модификаторы **Ctrl, Alt,
  Esc** и **стрелки**.
- Ряд **виден только с экранной клавиатурой** и исчезает при подключении
  аппаратной (освобождает место).
- В Blink Code (VS Code) та же OSK, модификаторы Ctrl/Cmd/Meta работают и там.
- Панель горячих клавиш вызывается с клавиатуры (⌘) — отдельный «шпаргалочный»
  экран.

**Что забрать:** принцип «модификаторы + стрелки всегда под рукой, остальное —
системная раскладка»; автоскрытие при аппаратной клавиатуре; шпаргалка по
сочетаниям как отдельная панель.

### 4.2 a-Shell
Источники: <https://holzschu.github.io/a-Shell_iOS/>,
<https://github.com/holzschu/a-shell>. Скриншот: `screens/ashell.png`.

- Терминал с локальным UNIX; над клавиатурой — ряд дополнительных клавиш
  (стрелки, Tab и служебные символы), чтобы работать с оболочкой без аппаратной
  клавиатуры.

**Что забрать:** компактный ряд «служебных» клавиш, не занимающий пол-экрана.

### 4.3 CodeBoard / Textastic / Working Copy / iSH
- **CodeBoard Keyboard for Coding** — специализированная клавиатура для кода:
  дополнительные символы и стрелки поверх QWERTY; ставится как системная.
- **Textastic**, **Working Copy** — редактор/Git-клиент с собственным рядом
  клавиш над системной клавиатурой (Tab, стрелки, символы кода).
- **iSH** — эмулятор Linux-пространства: ряд спецклавиш (Esc, Ctrl, стрелки).

Общая формула iOS-приложений: **системная QWERTY + узкий ряд спецклавиш сверху**,
а не «своя клавиатура целиком». Это экономит экран и привычки пользователя.

## 6. Рекомендации для cterm/aurora OSK

> **Актуально — `pkg/fyneosk/OSK-SPEC.txt` v1.0 (2026-11-21).** Раздел ниже — исходные
> рекомендации обзора; итоговые требования и точные раскладки (портрет/ландшафт,
> `--osk-compact`, свёрнутый ряд, цвета CMYK, VOL-/VOL+ = Ctrl/Alt, Fn/F1–F12,
> Ё) зафиксированы в спецификации. Отличия от текста ниже:
> * кнопки громкости — **обязательны** (R6), а не «опция для телефонов»;
> * цифровой ряд — **опция** `--osk-compact` (совмещён с qwerty, как на
>   `screens/unexpected-1.png`), а не «полный режим по умолчанию»;
> * RU/EN — на месте CapsLock (R11);
> * модификаторы — трёхсостоянийные с половинной заливкой (R4/R5).

### 6.1 Компоновка (портрет 1216×1920, планшет)

```
+------------------------------------------------------------+
| [Esc] [Tab] [Ctrl] [Alt] [Shift]  [←][↓][↑][→]  [⌫][⏎]     |  ряд 1: спецклавиши
+------------------------------------------------------------+
| 1 2 3 4 5 6 7 8 9 0 - = ⌫                                  |  ряд 2: цифры (опция)
+------------------------------------------------------------+
| q w e r t y u i o p [ ]                                    |  ряд 3
| a s d f g h j k l ; ' \                                    |  ряд 4
| ⇧ z x c v b n m , . / ⇧                                    |  ряд 5
+------------------------------------------------------------+
| [RU/EN] [Ctrl-lock] [Alt-lock] [Shift-lock] [Tab] [..]     |  ряд 6: переключатели
+------------------------------------------------------------+
```

- Ряд 1 — **всегда видимые** Esc/Tab/Ctrl/Alt/Shift, стрелки, Backspace/Enter.
- Ряд 2 (цифры + символы) — включается в «полном» режиме (как у Hacker's).
- Липкость модификаторов: тап — на следующую клавишу, двойной тап — блокировка
  (индикация цветом темы). Сброс — повторный тап или Esc.
- Свайпы по клавишам к углам — для символов `~ | \ { } [ ] $ ^` (идея Unexpected
  Keyboard): экономит переключение раскладок.
- Переключение EN/RU — кнопка + свайп по пробелу; состояние запоминается.

### 6.2 Три режима, переключаемые на ходу
1. **terminal** (умолчание) — ряд 1 + QWERTY, крупные клавиши, минимум высоты;
2. **full** — + цифровой ряд и блок Home/End/PgUp/PgDn/Del/Ins (планшет);
3. **compact** — только ряд 1 (модификаторы/стрелки), для набора с системной
   раскладкой (если она появится) и экономии экрана.

### 6.3 Поведение
- OSK **не перекрывает строку ввода**: при показе терминальная сетка
  уменьшается на высоту OSK (SIGWINCH), как при ресайзе окна.
- Показ/скрытие: тап по области ввода, свайп вниз по OSK, кнопка в панели
  вкладок; автоскрытие при подключении аппаратной клавиатуры.
- Модификаторы отправляют настоящие коды (Ctrl+A = 0x01, Alt = ESC-префикс),
  а не «нажатия» — терминальные программы (vim, mc, tmux, readline) работают
  без изменений.
- Клавиши F1..F12 — во второй странице ряда 1 (свайп по ряду), не отдельным
  экраном.
- Долгое нажатие — повтор клавиши (стрелки, Backspace), с настраиваемой
  задержкой.
- Вся OSK — в палитре темы терминала (SPEC W5/W6): контраст ≥ 3:1 по WCAG,
  проверяется тестом, как остальной UI.

### 6.4 Кнопки громкости (Termux-схема) — опция
На **телефонах** полезно: Volume Down = Ctrl, Volume Up + E = Esc, +T = Tab,
+1..0 = F1..F10. На **планшете NS220** — неудобно и перехватывается системой,
поэтому по умолчанию **выключено**; ключ `terminal.volume-keys: off|ctrl`
(если включено — подсказка в статусе).
