## Почему снимки самим приложением

`busctl --user call org.nemomobile.lipstick … saveScreenshot` отвечает
`Access denied`: lipstick разрешает снимок только своему/разрешённому клиенту.
Поэтому в приложении есть флаг `-shot PATH -shot-delay D` — он снимает canvas
через Fyne и пишет PNG; это же используется в автоматических проверках
(`scripts/deploy.sh --run --shot`).
